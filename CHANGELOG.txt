
## Amendments to Specifications

- **TRD 17.1 (Migration Files):** Amended file naming convention from sequential integers (001_types.sql) to millisecond timestamps (<timestamp>_types.sql) as generated by node-pg-migrate. This prevents collision when multiple developers add migrations on the same day. Migrations are ordered by timestamp.

- Amended TRD 5.10 (audit_log): detail column type changed from VARCHAR(400) to JSONB to allow structured storage (e.g., reason_json).
- Amended TRD 5.10 (audit_log): ck_audit_status_change was modified from a strict biconditional to an implication (ck_audit_status_change) and a sanity check (ck_audit_status_differ), because the strict biconditional forbade status transitions during other labelled actions (e.g., CLAIM_APPROVED).
