# T2.11 Index Evidence

## Index Definitions
The following partial indexes are used to optimize matching probe queries:

```sql
CREATE INDEX ix_found_match_probe ON found_items (category_id, found_date, status) WHERE status = 'AVAILABLE';
CREATE INDEX ix_lost_match_probe ON lost_items (category_id, lost_date, status) WHERE status = 'OPEN';
```

## `ix_found_match_probe` Execution Plan
Tested on `found_items` containing >50,000 generated records.

Query:
```sql
EXPLAIN ANALYZE SELECT f.found_id, f.found_date FROM found_items f WHERE f.status = 'AVAILABLE' AND f.category_id = (SELECT category_id FROM categories LIMIT 1) AND f.found_date >= (CURRENT_DATE - INTERVAL '14 days');
```
